How it works

  1. On the main computer: Create room. Write down the 4-letter code. Pick the video. Its length sets the loop.
  2. On every other computer: type the code, Join, pick that computer's video.
  3. Click once to start. Everything loops forever, in sync.
  4. Next time you open the site, each computer goes straight back to its room and video.

Move the mouse to show controls. Keys: space pause, ← → jump 5 s, R restart everyone (main computer only), F fullscreen, [ ] delay ±10 ms (hold shift for ±1 ms).

If one screen looks a little late or early (slow TV, external speakers), adjust its delay until it matches.

Best browser

Chrome or Edge. They play the video straight from your disk, so files of any size work. Firefox and Safari work too, but they first copy the video into the browser's storage (needs free disk space the size of the video).

Skip the "click to start" screen

Browsers need one click before playing sound fullscreen. To start fully automatically (for example after a power cut), open the site in kiosk mode:

Windows — make a shortcut with this target (put it in the Startup folder to run at boot):

"C:\Program Files\Google\Chrome\Application\chrome.exe" --kiosk --autoplay-policy=no-user-gesture-required https://YOUR-SITE.workers.dev

Mac — run in Terminal (or save as an Automator app and add it to Login Items):

open -na "Google Chrome" --args --kiosk --autoplay-policy=no-user-gesture-required https://YOUR-SITE.workers.dev

To exit kiosk mode: Alt+F4 (Windows) or Cmd+Q (Mac).

Chrome may ask once for permission to read the video file. Choose Allow on every visit.

Firefox: click the icon left of the address → Autoplay → Allow Audio and Video, and press F11 for fullscreen. Safari: Safari → Settings for this website → Auto-Play → Allow All Auto-Play.

Exhibition checklist

  • Turn off sleep / screen saver on every computer.
  • Turn off OS notifications (Do Not Disturb / Focus).
  • All computers need Wi-Fi only for sync. The video plays from the computer itself.
  • If the Wi-Fi drops, playback continues in sync on its own.

Cómo funciona

  1. En la computadora principal: Crear sala. Anota el código de 4 caracteres. Elige el video. Su duración define el loop.
  2. En cada una de las otras computadoras: escribe el código, Unirse, y elige el video de esa computadora.
  3. Un clic para empezar. Todo se repite en loop para siempre, sincronizado.
  4. La próxima vez que abras el sitio, cada computadora vuelve sola a su sala y a su video.

Mueve el mouse para ver los controles. Teclas: espacio pausa, ← → saltar 5 s, R reiniciar a todos (solo la computadora principal), F pantalla completa, [ ] retraso ±10 ms (con shift ±1 ms).

Si una pantalla se ve un poco adelantada o atrasada (un televisor lento, altavoces externos), ajusta su retraso (DELAY) hasta que coincida.

Mejor navegador

Chrome o Edge. Reproducen el video directo desde el disco, así que funcionan archivos de cualquier tamaño. Firefox y Safari también funcionan, pero primero copian el video al almacenamiento del navegador (hace falta espacio libre del tamaño del video).

Saltar la pantalla "clic para empezar"

Los navegadores piden un clic antes de reproducir con sonido en pantalla completa. Para que arranque solo (por ejemplo después de un corte de luz), abre el sitio en modo kiosco:

Windows — crea un acceso directo con este destino (ponlo en la carpeta Inicio para que arranque al encender):

"C:\Program Files\Google\Chrome\Application\chrome.exe" --kiosk --autoplay-policy=no-user-gesture-required https://TU-SITIO.workers.dev

Mac — ejecuta esto en Terminal (o guárdalo como app de Automator y agrégalo a Ítems de inicio):

open -na "Google Chrome" --args --kiosk --autoplay-policy=no-user-gesture-required https://TU-SITIO.workers.dev

Para salir del modo kiosco: Alt+F4 (Windows) o Cmd+Q (Mac).

Chrome puede pedir una vez permiso para leer el archivo de video. Elige Permitir en cada visita.

Firefox: clic en el ícono a la izquierda de la dirección → Reproducción automática → Permitir audio y video, y F11 para pantalla completa. Safari: Safari → Ajustes de este sitio web → Reproducción automática → Permitir toda la reproducción automática.

Checklist para la exhibición

  • Desactiva la suspensión y el protector de pantalla en todas las computadoras.
  • Desactiva las notificaciones del sistema (No molestar / Concentración).
  • El Wi-Fi solo se usa para sincronizar. El video se reproduce desde cada computadora.
  • Si se corta el Wi-Fi, la reproducción sigue sincronizada sola.
