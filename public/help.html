How it works

  1. On the main computer: Create room. Write down the 4-letter code. Pick the video. Its length sets the loop.
  2. On every other computer: type the code, Join, pick that computer's video.
  3. Click once to start. Everything loops forever, in sync.
  4. Next time you open the site, each computer goes straight back to its room and video.

Move the mouse to show controls. Keys: space pause, ← → jump 5 s, R restart everyone (main computer only), F fullscreen, [ ] delay ±10 ms (hold shift for ±1 ms).

If one screen looks a little late or early (slow TV, external speakers), adjust its delay until it matches.

Best browser

Chrome or Edge. They play the video straight from your disk, so files of any size work. Firefox and Safari work too, but they first copy the video into the browser's storage (needs free disk space the size of the video).

Skip the "click to start" screen

Browsers need one click before playing sound fullscreen. To start fully automatically (for example after a power cut), open the site in kiosk mode:

Windows — make a shortcut with this target (put it in the Startup folder to run at boot):

"C:\Program Files\Google\Chrome\Application\chrome.exe" --kiosk --autoplay-policy=no-user-gesture-required https://YOUR-SITE.workers.dev

Mac — run in Terminal (or save as an Automator app and add it to Login Items):

open -na "Google Chrome" --args --kiosk --autoplay-policy=no-user-gesture-required https://YOUR-SITE.workers.dev

To exit kiosk mode: Alt+F4 (Windows) or Cmd+Q (Mac).

Chrome may ask once for permission to read the video file. Choose Allow on every visit.

Firefox: click the icon left of the address → Autoplay → Allow Audio and Video, and press F11 for fullscreen. Safari: Safari → Settings for this website → Auto-Play → Allow All Auto-Play.

Exhibition checklist

  • Turn off sleep / screen saver on every computer.
  • Turn off OS notifications (Do Not Disturb / Focus).
  • All computers need Wi-Fi only for sync. The video plays from the computer itself.
  • If the Wi-Fi drops, playback continues in sync on its own.
